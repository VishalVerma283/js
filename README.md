💰 Expense Tracker

A simple and user-friendly Expense Tracker built with HTML, CSS, and JavaScript.

✨ Features

➕ Add income

➖ Add expenses

💰 Calculate total balance

📈 Track total income

📉 Track total expenses

🏷️ Categorize transactions

🎨 Category-based icons

🗑️ Delete transactions

💾 Save data using Local Storage

🔄 Automatically load saved transactions after refresh

🆔 Generate unique transaction IDs

🛠️ Technologies Used

HTML5

CSS3

JavaScript

DOM Manipulation

Local Storage API

📂 Categories

🍔 Food

🚗 Travel

🛍️ Shopping

💡 Bills

💼 Salary

🧮 Balance Calculation
Balance = Total Income - Total Expense

💾 Local Storage

All transactions are stored in the browser using Local Storage, so the data remains available after refreshing the page.

🚀 How to Run

Clone this repository:

git clone <your-repository-url>


Open the project folder.

Open index.html in your browser.

No backend or database is required.

🔄 How It Works

User enters transaction details.

A transaction object is created.

The transaction is added to the expenses array.

Data is saved to Local Storage.

Transactions are displayed on the page.

Total income, expenses, and balance are calculated automatically.

🗑️ Delete Transaction

Users can delete any transaction using the delete button. The transaction is removed from the list and Local Storage is updated automatically.
